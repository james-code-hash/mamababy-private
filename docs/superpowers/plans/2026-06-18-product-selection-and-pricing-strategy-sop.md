## 🎯 一、 選品戰略：爆款金字塔梯隊管理 (Pyramid Sourcing)

為了解決蝦皮「低毛利紅海價格戰」與「1688 圖片同質化」的痛點，本系統放棄傳統盲目鋪貨，全面實施 **「爆款金字塔」梯隊管理法**，將流量、精力與資金精準分配：

```text
       ▲ [第一梯隊] 爆款主推款（Top 5%） ──> 1688批貨回台自出（海運3元/kg）+ ComfyUI人工細緻中文化
      / ＼
     /   ＼ [第二梯隊] 灰度測試款（Top 15%）──> 一件代發（12元/kg）+ AI快速繁體翻譯
    /_______＼
```

### 1. 第一階段：大數據初選與灰度上架（測試期）
* **篩選機制**：
  * 每週定時調用 `python3 main.py zhixia word-hot` 與 `word-surge`。
  * 篩選 30 天銷量大於 3,000 件，但市場競爭商品數小於 100 的「藍海詞/黑馬品」。
  * 篩選出 1688 新品上架且蝦皮上「同質化商家小於 10 家」的商品。
* **維護與履約**：
  * 採用 **「方案 A（一件代發/DropShipping）」** 履約，**零庫存、零資金積壓風險**。
  * 主圖直接採用 1688 乾淨的白底圖，文案由系統 LLM（Gemini/DeepSeek）自動翻譯為繁體字並替換台灣本土用語，快速批量上架測試水溫。

### 2. 第二階段：爆款晉升與批量海運（爆發期）
* **觸發指標**：一旦灰度測試商品在蝦皮**產生詢問、高收藏或自然出單**。
* **維護與履約**：
  * **立刻升級為「主推爆款」**，發起 1688 批量採購（首批 20~50 件，採購金額控制在 $1,500~$2,000 元台幣安全閥內）。
  * 採用 **「方案 B（海運批貨回台自出貨，3 CNY/kg）」** 履約，將單件運費降到最低，毛利榨取到最大（50%~60%）。
  * **啟動多媒體精修管線**：調用 ComfyUI 智慧畫廠抹除水印、替換繁體包裝、重置北歐高質感場景，製作痛點主圖，並補齊詳情 Metadata。

## 📈 二、 上架定價戰略：10% 蝦幣回饋「平日與促銷檔期」雙軌計費

我們參加了蝦皮的 **「10% 蝦幣回饋活動 + 免運方案一 + 較長備貨」** 頂級促銷組合。這套組合在平日與促銷檔期有完全不同的平台抽成費率，我們建立了**平日與檔期雙軌倒推公式**：

### 1. 蝦皮費率結構對比
| 費用項目 | 平日（Normal Day） | 促銷檔期（Campaign Day） |
| :--- | :--- | :--- |
| **成交手續費** | `5.5%` | **免收** (參加活動者專屬優惠) |
| **免運補貼費率** | `6.0%` | `6.0%` |
| **較長備貨手續費** | `3.0%` | `3.0%` |
| **金流與系統處理費** | `2.5%` | `2.5%` |
| **蝦幣 10% 回饋抽成** | `3.0%` | `3.0%` |
| **合計總抽成費率** | **`20.0%`** | **`14.5%`** (省下 5.5 個百分點！) |

* **反直覺暴利點**：在促銷檔期，您的單位手續費成本不升反降（少了 5.5%），此時您的定價具有極致彈性！

### 2. 科學定價反向倒推公式
為了守住您 **`50%`** 的目標淨利潤率（`TARGET_MARGIN_RATE = 0.50`）：

#### **平日建議售價（守住基本盤利潤）：**
$$\text{建議售價}_{\text{平日}} = \frac{\text{台幣總成本}}{1 - 0.20 - 0.50} = \frac{\text{台幣總成本}}{0.30}$$

#### **促銷檔期建議售價（降價衝量，或維持原價暴利）：**
$$\text{建議售價}_{\text{促銷檔期}} = \frac{\text{台幣總成本}}{1 - 0.145 - 0.50} = \frac{\text{台幣總成本}}{0.355}$$

## 🛠️ 三、 1688 來源商品多媒體維護與 AI 精修管線

為了讓商品具備「台灣本土品牌旗艦店」的極致質感，我們對 1688 的文字、主圖、詳情圖、影片與 Metadata 進行了多維度維護：

### 1. 文字與 Metadata 本地化 (Text & Metadata)
* **自動翻譯與詞彙對接**：
  呼叫系統內建的大語言模型，一鍵將簡體文字替換為台灣繁體，並強制轉換兩岸電商用語：
  * *詞彙對照*：`宝贝描述 -> 商品詳情` | `快递/物流 -> 寄送/超商取貨` | `猫粮/狗粮 -> 貓飼料/狗飼料` | `充电宝 -> 行動電源` | `性价比 -> CP值`。
* **Metadata 補齊**：
  直接抓取並在 BigSeller 登錄 1688 的**精確重量（克重）與包裝尺寸**（長、寬、高），以便我們的高精度利潤引擎進行運費分攤，並防止蝦皮買家下單時發生超材拒收。

### 2. 圖片與場景重置 (ComfyUI AI 圖片管線)
我們在本地 M 晶片 Mac 上啟動 ComfyUI 伺服器，利用 API 客戶端（`utils/comfyui_client.py`）進行自動化處理：
* **智慧去水印 (Inpainting)**：
  發送 1688 主圖至 ComfyUI API，呼叫 Inpaint 節點，自動識別並抹除簡體水印，或者將包裝上的簡體字無縫重繪為高品質繁體字。
* **場景置換 (Product Relighting)**：
  對於 1688 凌亂的工廠實拍圖：
  * 使用 **Segment Anything** 節點提取寵物碗、玩具等商品主體。
  * 利用 **Flux / SDXL** 模型，將商品無縫融入「北歐簡約風寵物客廳」、「暖陽灑落的精緻木地板」等高端 3D 模擬場景。
  * 自動生成物理陰影與真實反光，瞬間提升視覺轉化率。

### 3. 影片本地化管線 (AI Video Localization)
* 下載 1688 的實拍展示影片。
* 通過 ComfyUI 的 **Reactor / AnimateDiff** 節點，自動淡化、模糊化或繁體化影片背景中廠家的簡體字招牌。
* 在蝦皮上架時，一鍵配置台灣本土高熱度流行音樂，作為吸睛短影音衝流量。

## 📊 四、 決策對比表：這款產品該批量進貨還是代發？

我們的高精度利潤引擎會直接在選品 Pipeline 中，根據您提供的真實貨代公式進行精算：
* **批貨回台自出成本** = `1688 採購價 + 5.0 (貼標費) + max(商品重量, 1kg) * 3 CNY/kg + (1688 國內運費 / 50)`。
* **一件代發件結成本** = `1688 採購價 + 5.0 (代發費) + (商品克重 * 12 CNY/kg) + 1688 國內運費`。

### 💡 決策臨界線
* 30天銷量小於 3,000 件 $\rightarrow$ **一律一件代發**（零資金壓貨風險）。
* 30天銷量大於 3,000 件且重量大於 1kg $\rightarrow$ **一律批量進貨回台**（代發物流成本過高，唯有批量海運進貨能釋放翻倍毛利！）。
* 30天銷量大於 3,000 件且重量小於 100g $\rightarrow$ **走一件代發**（海運與海快差額極小，走代發免除理庫存與貼標精力）。
