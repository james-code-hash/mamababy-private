# 《帕帕貝貝家》編劇與分鏡

你寫的是 45–120 秒（目標 55–65 秒）的直式紙偶情境喜劇：帕帕（橘貓，唯一說話的角色）吐槽新手爸爸，媽媽或帕帕示範正確做法，最後一個反轉笑點。台灣用語、繁體中文。
輸出是一份**高階分鏡 JSON**（只寫名字不寫座標）；程式會驗證、算相機與站位、渲染。

## 工作方式（Claude Code 工作階段；整個做一集的流程看 skill `papa-home-episode`）

1. `python main.py papa bible`：設定集（角色、孩子年齡、季節、固定哏、最近幾集）。集數＝設定集的下一集。
2. 題目與出處：`python main.py papa sources <網址> --keyword …` 抓官方原文切句（只收白名單網域），挑要用的句子放進分鏡的 `sources`（`{"S1": {"url", "quotes": [原句…]}}`）。
3. 讀 `references/structure.md`（一集怎麼排）、`references/text-rules.md`（泡泡字數、停留秒數）、`references/format.md`（每個欄位）。
4. 讀 skill `papa-home-motion`：`references/characters.md`（誰有哪些姿勢、表情）與 `references/motions.md`（能做哪些動作、套路）。**表演只能用那裡列出的名字**；缺動作照 `references/adding-motions.md` 加進動作庫。
5. 參考 `episodes/` 裡最近一集的格式與節奏（還沒有就看封存的 `episodes/archive/ep01_baby.json`，那集的寶寶已退役），內容要完全不同。
6. 分鏡寫到 `libs/content/mamababy_private/papa_home/episodes/epNN.json`（進 repo），`python main.py papa validate <檔> --fix` 到沒有 ✗，`!` 警告也要處理。

依審片意見改時：**只改被點名的鏡頭**（其他鏡頭一個字都不要動，鏡號也不變），改完再驗證。改長度時記得總長還要在範圍內、精華版 `cut` 引用的鏡號都還在。

## 一定要守的

- **知識點只能根據官方來源原句**：第二幕的每張步驟字卡（`step`）要帶 `source`（S1…）和 `quote`（從分鏡 `sources` 裡逐字複製的一句），字卡文字裡的數字要出現在那一句；台詞裡的數字只能是來源原句裡有的、寶寶月齡、或集數。不給醫療建議，只能說「出現 X 就去看醫生」。
- 只有帕帕說話；不推商品、不寫價格、不說品牌名；寶寶不碰寵物毛、不靠近危險物；不畫人臉。
- 台詞提到的東西畫面上要看得到：只能講素材清單裡有的道具與動作。
- 道具要合情節：手部特寫看說明挑（例：餵副食品用 `mom_spoon`，不要拿梳子、奶瓶代替）。清單裡沒有合適的道具，就照 `scripts/papa_props.py` 生一張（自己看過、驗證過才用），不要拿別的東西代替。
- 每個情節點都要有人在「演」：關掉字幕也要看得懂（誰犯錯、誰難受、誰舒服、誰看誰）。說話的帕帕寫 `mouth: "talk"`。
- 3 秒以上的 WIDE／CU／REACTION／POV／INSERT 要有動作事件（角色移動或動作、飄毛、道具、表情變化、擬聲字、定格），不能像投影片。
- 數值欄位寫數字（`"dur": 2.0`，不是「兩秒」）；型別錯會被整份退回。

## 好分鏡的樣子

- 冷開場第 0 格就有角色和一句帕帕的吐槽（這格是縮圖）。
- 笑點有鋪陳：揭曉句前一句引子；爸爸犯的每個錯，後面都有一句或一張字卡回應。
- 每 10–15 秒一個新的小鉤子；台詞 15–18 句。
- 本集最重要的那句知識一定做成一張步驟字卡。
- 精華版 `cut` 挑 8–10 鏡約 25 秒：冷開場＋步驟＋反轉＋收尾。
